 ## Secrets Project

[![Build Status](https://shields.io)](https://shields.io)
[![License: MIT](https://shields.io)](https://opensource.org)

a secret project app inspired by whisper app.This project was for strengthening my backend journey especially for node/express ecosystem and Rest Apis using Axios.


## 🛠️ Tech Stack
- **Frontend**: EJS(SSR)
- **Backend**: Node.js,Express.js and Axios
- **DevOps**:  GitHub 

## 📦 Prerequisites
Before setting up, ensure you have the following global dependencies installed:
- Node.js (v18.0.0 or higher)
- npm (v9.0.0 or higher)
- Git

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/secretsApp.git
   cd secretsApp
   ```

2. **Install project dependencies:**
   ```bash
   npm install or npm i 
   ```

## Starting the server
```bash
nodemon index.js
```
